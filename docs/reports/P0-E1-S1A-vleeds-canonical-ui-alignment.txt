13. CANONICAL-REFERENCE MISMATCHES (intentional)
--------------------------------------------------------------------------------
M1  Mobile summary labels: the canonical mobile reference uses
    "Calls due / Follow-ups / New leads / Discoveries", which conflicts with
    desktop "A leads ready / callbacks due / follow-ups / new discoveries" for
    the same icons. Mobile uses short forms of the desktop metrics
    ("Calls due / Callbacks / Follow-ups / Discoveries") so one metric has one
    meaning.
M2  Notification bell has no unread dot: there are no notifications; a dot
    would misrepresent state. The panel says "No notifications".
M3  Avatar shows initials, not a photo: no profile photos exist.
M4  Settings "Edit" is shown but aria-disabled (slightly muted), and the
    configuration-row chevrons are present but the rows are not links:
    editing arrives in P0-E1-S2. Making them look active would mislead.
M5  Search is a real input (⌘K / Ctrl+K focuses it) but shows "Search …
    becomes available once this workspace has leads". There is no search
    backend (by instruction).
M6  Desktop Today (real) shows no search/filter buttons on the queue panel
    when it is empty (nothing to filter); the fixture shows them.
M7  Mobile header at 360-384px shows the V mark without the wordmark, and the
    briefcase icon in the workspace pill is hidden below 400px, so the
    workspace name keeps room. Long names truncate with an ellipsis (full name
    in title and the sheet); "Alpha Workspace" is clipped by a few pixels at
    390px.
M8  Muted text is #6f757c, slightly darker than the reference grey, to meet
    WCAG AA on white.
M9  Fixture drawer is 360px wide below 1536px (400px at 2xl) so the table
    stays readable at 1440px; columns still wrap more than in the wider
    reference.
M10 Fixture data uses generic companies and signals instead of the
    reference's example businesses/industries (business-agnostic rule).
M11 The workspace-selector name underline was reproduced as a subtle
    underline, as in both references.

  disabled Edit announces "(not available yet)".
